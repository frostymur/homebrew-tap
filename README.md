# Homebrew Tap for aerofi

This is the official Homebrew tap for [aerofi](https://github.com/frostymur/aerofi), a lightweight, keyboard- and mouse-driven script launcher for macOS.

## Installation

```bash
brew install frostymur/tap/aerofi
```

Or you can add the tap first and then install:

```bash
brew tap frostymur/tap
brew install aerofi

# Start as a background service (starts automatically at login)
brew services start aerofi
```
